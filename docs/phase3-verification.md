## 2. 정확도 평가 상세 (Phase 0 방식, 실제 앱 산출물)

- 대상 1: 터미널 캡처 @2x→1/2 다운스케일(1028x400). 블라인드 지목: rect 영역·arrow 머리 단어("feature") 정확, point는 좌표-링 픽셀 일치(11px 한글 명명만 비전 한계).
- 대상 2: 터미널 캡처 @2x 네이티브(1140x776, `scale: 2 image px = 1 CSS px`). 비전 에이전트 3/3("Running"·localhost:1420 링크·CPU 14%) + 환산 질문(127 image px→63.5 CSS px) 정확. 비전 금지 에이전트도 상대 위치 3/3·scale 해석 정확.
- 다운스케일 두 분기(1/2·native) 모두 실물로 검증됨.
